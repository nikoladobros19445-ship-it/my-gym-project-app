# 🏋️‍♀️ Gym Booking App

A full-stack **Next.js + Firebase** web application for reserving gym time slots with **user** and **admin** roles.

---

## ✨ Features
- **User**
  - Register / Sign-in with Firebase Authentication
  - Reserve a future gym slot
  - View and cancel own upcoming bookings
- **Admin**
  - See all users’ bookings (with user email & date/time)
  - Cancel any booking
- **Role-based access control** stored in Firestore
- Responsive UI built with **Tailwind CSS**
